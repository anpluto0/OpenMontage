# Шаблон: как сделать следующий ролик в этом формате

Ролик Green Express × Яндекс Еда (9:16, 24 с, 2D «всё из квадратов») собран как шаблон:
тексты экрана и звук вынесены в два файла настроек, вёрстка и анимация — в `hyperframes/index.html`.

## Что где лежит

| Что | Файл | Когда трогать |
|---|---|---|
| Все надписи на экране (45 ключей по сценам) | `hyperframes/content.js` | Новый текст — правите только значения |
| Реплики диктора, их время, музыка, SFX, громкость | `assets/audio/cues.json` | Новый текст диктора / новые точки звуков |
| Озвучка недостающих реплик (Prince Nur, eleven_v4) | `assets/audio/make_voice.py` | После правки `lines` в cues.json |
| Сведение дорожки | `assets/audio/mix.py` | Запускать после любых правок звука |
| Сцены, персонаж, анимация, тайминги сцен | `hyperframes/index.html` | Новые сцены / другой порядок |
| Логотипы | `hyperframes/assets/ge_mark.svg` + `ge_wordmark.svg` (из официального `assets/brand/green_express_logo_official.svg`), Яндекс Еда — PNG | Если пришлют официальный SVG Яндекс Еды |
| История решений и правок пользователя | `HANDOFF.md` | Читать перед работой |

## Сценарий 1 — тот же сюжет, другой текст (самый быстрый)

1. Поправить надписи в `hyperframes/content.js`. Длинные строки проверить на скриншоте — переносов нет,
   ширина заголовка ~888 px при 96 px шрифта (≈ 16–18 символов в строке).
2. Поправить `text` реплик в `assets/audio/cues.json`. Для каждой изменённой реплики удалить её `.wav`
   из `assets/audio/vo/` (или передать `--force <id>`), затем из корня репозитория:
   ```bash
   python3 projects/green-express-courier-ad/assets/audio/make_voice.py projects/green-express-courier-ad/assets/audio/cues.json
   ```
   Скрипт выведет длительность каждой новой реплики — проверьте, что `start + длительность` не наезжает
   на следующую реплику и укладывается в свою сцену (тайминги ниже).
3. Свести и собрать:
   ```bash
   cd projects/green-express-courier-ad/assets/audio && python3 mix.py cues.json mix.wav
   cd ../../hyperframes && npx -y hyperframes@0.9.8 render --quality standard -o ../renders/draft_silent.mp4
   cd .. && ffmpeg -i renders/draft_silent.mp4 -i assets/audio/mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart renders/final.mp4
   ```

## Тайминги сцен (секунды ролика)

| Сцена | Время | Реплика | Ключевые события (SFX в cues.json) |
|---|---|---|---|
| 1 Хук | 0–2.9 | A 0.25 | календарь, баланс 0 ₸ |
| 2 Проблемы | 2.9–8.6 | B 3.3 · C 4.5 · D 5.85 | карточки 3.3 / 4.55 / 5.95 |
| переход | 8.6–9.25 | — | сдвиг вверх: проблемы уезжают, жёлтая сцена въезжает снизу |
| 3 Поворот | 9.25–11.6 | E2 9.3 | герой выезжает, лайк |
| 4 График | 11.75–14.0 | F 11.8 | день → ночь 12.55, «Начать смену» 13.65 |
| 5 Выплаты | 14.1–17.5 | G 14.25 | выплата 15.45, монеты 15.65–16.4 |
| 6 CTA | 17.75–24 | H 17.85 | клик 19.82, сообщение 20.1 |

В `index.html` позиции анимаций записаны в «базе v1» и пересчитываются функцией `T()` в начале таймлайна
(блок проблем сжат, всё после 9.9 с сдвинуто на −1.3 с). Новые твины пишите в той же базе
(время ролика + 1.3 для всего после поворота) или замените `T` на тождественную функцию и перепишите
позиции в реальном времени.

## Сценарий 2 — новые сцены

Копировать `index.html` и переставлять блоки `<!-- ===== Sx ===== -->` + соответствующий кусок таймлайна.
Персонаж — SVG-символы `#heroBag/#heroBody/#heroHead/#heroEyes/#heroArm`; анимировать только трансформами
и **только с `svgOrigin`** (с `transformOrigin` в px части персонажа «улетают»).

## Правила, которые уже согласованы с заказчиком

- Голос: ElevenLabs **Prince Nur** (`gJEfHTTiifXEDmO687lC`), `eleven_v4`, stability 0.45, similarity 0.8, seed 7.
  «Green Express» в тексте диктора — «Грин Экспресс», WhatsApp — «Ватсап». RHVoice не использовать.
- Город не называть (таргет на разные города). Цифр заработка нет.
- SFX переходов/кликов — стандартные (Pixabay, `sfx/whoosh-short`, `pop`, `click`); уведомление — «в духе iPhone»,
  но не оригинальный звук Apple.
- Монеты — игровые круглые, без вращения ребром. Указатель — курсор-стрелка, не рука.
- CTA: логотипы в одном симметричном белом блоке (официальный SVG Green Express); сообщение «Хочу стать курьером» без галочек.
- На термосумке героя логотипа нет.
- Переходы — сдвигом сцен (как 1→2, 4→5), без «заливок» и разлёта осколков.
- Музыка: `music/bgm_v1_ext.mp3` (ElevenLabs Music, 112 BPM, подъём ~8 с, финальный удар ~23.9 с).

## Проверка перед отправкой

- Кадры: Playwright, `window.__timelines.main.seek(t)` (в `page.evaluate` оборачивать в `{ }`, иначе
  Playwright пытается сериализовать таймлайн и вкладка падает).
- `npx hyperframes lint` — в папке `hyperframes/` должен быть один корневой `index.html`.
- Звук: `ffmpeg -i mix.wav -af ebur128=peak=true -f null -` → около −14 LUFS, пик ≤ −1.5 dBFS.
