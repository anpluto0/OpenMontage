# «Курьер — батыр» · Выпуск 1 · «А если бы это была моя мама?» — RU, сценарий v4

Правки v3 — по разбору фреймворками marketingskills (coreyhaines31, MIT: social/short-form-video, marketing-psychology, copy-editing, video/edit-anatomy): оценка v2 — 7,2/10.
Изменено: хук-текст с первого кадра; линейная хронология без повтора; имя героя в момент тишины; голосом призыв «Отправьте это родителям»; финал разделён (совет → фото+источники); убраны «плащ» и тире-афоризмы. Дата «Алматы, лето 2026» остаётся первой фразой голоса (пожелание клиента), но короткой.
v4: хук без намёка, что курьер — вор («Бабушка чуть не отдала мошенникам $3 000. Её спас курьер»); финал — «Спасибо таким курьерам. Больше таких историй у нас в аккаунте» + подсказка подписаться.
Герой — не курьер Green Express; маскот-курьер в нейтральной форме; Green Express только на финальной плашке.
